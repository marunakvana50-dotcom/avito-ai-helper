# ИИ-помощник продавца на Авито (Telegram-бот)

Первая рабочая версия. Продавец пишет боту в Telegram:

- 📷 присылает **фото товара** — бот разбирает кадр (свет, фон, ракурс, чёткость)
  и советует, как переснять, чтобы товар смотрелся лучше;
- ✍️ присылает **текст описания** — бот переписывает его в продающее объявление.

Функции сравнения цены и оценки спроса пока не входят: у Авито нет официального
доступа к данным по ценам и объявлениям (это узкое место), поэтому начинаем с двух
функций, которые полностью и надёжно решает нейросеть.

---

## Что нужно один раз получить

1. **Токен Telegram-бота.** В Telegram найди бота **@BotFather**, отправь ему
   команду `/newbot`, придумай имя — он выдаст длинный токен. Скопируй его.
2. **Ключ нейросети Claude.** Зайди на **console.anthropic.com**, зарегистрируйся,
   пополни баланс (на старте хватит совсем немного) и создай API-ключ. Скопируй его.

---

## Установка и запуск (по шагам)

Нужен установленный **Python 3.10 или новее** (скачать: python.org).

1. Скачай проект и открой папку с ним в терминале.

2. Установи зависимости (одной командой):
   ```
   pip install -r requirements.txt
   ```

3. Создай файл с секретами. Скопируй `.env.example` в файл с именем `.env`:
   ```
   cp .env.example .env
   ```
   (в Windows: `copy .env.example .env`)

4. Открой файл `.env` в блокноте и впиши свои значения:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather;
   - `ANTHROPIC_API_KEY` — ключ с console.anthropic.com.

5. Запусти бота:
   ```
   python bot.py
   ```
   Если всё верно, увидишь строку «Бот запущен».

6. Открой своего бота в Telegram, нажми **Start** (или отправь `/start`) и
   пришли ему фото товара или текст описания.

Чтобы остановить бота — нажми `Ctrl + C` в терминале.

---

## Как проверить, что всё работает

1. Отправь боту `/start` — должно прийти приветствие.
2. Пришли реальное фото кроссовок — придёт разбор кадра с советами.
3. Пришли реальный текст описания — придёт переписанный продающий вариант.
4. Прогони так 5–10 своих настоящих объявлений и оцени, полезны ли советы.

---

## Из чего состоит проект

- `bot.py` — сам бот: принимает фото и текст, отправляет ответы.
- `claude_client.py` — связь с нейросетью (две функции: разбор фото, рерайт текста).
- `prompts.py` — тексты-инструкции для нейросети. **Их можно править**, чтобы
  менять стиль советов, не трогая остальной код.
- `requirements.txt` — список нужных библиотек.
- `.env.example` — образец файла с секретами (сам `.env` в git не попадает).

---

## Сколько это стоит

- Telegram и сам бот — бесплатно.
- Платишь только за обращения к нейросети — обычно копейки-рубли за один товар.
- Хочешь дешевле — в файле `.env` раскомментируй строку
  `ANTHROPIC_MODEL=claude-haiku-4-5` (модель дешевле и быстрее, но чуть проще).

## Что дальше (после проверки первой версии)

- **Цена** — полуручной вариант: продавец сам вводит 2–3 цены похожих объявлений,
  нейросеть даёт вывод «дорого / нормально / дёшево».
- **Спрос** — приблизительная прикидка (не точные данные Авито, а общая оценка).
- **Красивый интерфейс** (мини-приложение в Telegram) — если идея взлетит.
