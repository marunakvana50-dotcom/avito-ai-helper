# ИИ-помощник продавца на Авито (Telegram-бот)

Первая рабочая версия. Продавец пишет боту в Telegram:

- 📷 присылает **фото товара** — бот разбирает кадр (свет, фон, ракурс, чёткость)
  и советует, как переснять, чтобы товар смотрелся лучше;
- ✍️ присылает **текст описания** — бот переписывает его в продающее объявление.

Функции сравнения цены и оценки спроса пока не входят: у Авито нет официального
доступа к данным по ценам и объявлениям (это узкое место), поэтому начинаем с двух
функций, которые полностью и надёжно решает нейросеть.

---

## Что нужно один раз получить

1. **Токен Telegram-бота.** В Telegram найди бота **@BotFather**, отправь ему
   команду `/newbot`, придумай имя — он выдаст длинный токен. Скопируй его.
2. **Ключ нейросети Gemini.** Зайди на **aistudio.google.com**, войди через
   Google-аккаунт и создай API-ключ (обычно бесплатно для старта). Скопируй его.

---

## Установка и запуск (по шагам)

Нужен установленный **Python 3.10 или новее** (скачать: python.org).

1. Скачай проект и открой папку с ним в терминале.

2. Установи зависимости (одной командой):
   ```
   pip install -r requirements.txt
   ```

3. Создай файл с секретами. Скопируй `.env.example` в файл с именем `.env`:
   ```
   cp .env.example .env
   ```
   (в Windows: `copy .env.example .env`)

4. Открой файл `.env` в блокноте и впиши свои значения:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather;
   - `GEMINI_API_KEY` — ключ с aistudio.google.com.

5. Запусти бота:
   ```
   python bot.py
   ```
   Если всё верно, увидишь строку «Бот запущен».

6. Открой своего бота в Telegram, нажми **Start** (или отправь `/start`) и
   пришли ему фото товара или текст описания.

Чтобы остановить бота — нажми `Ctrl + C` в терминале.

---

## Как проверить, что всё работает

1. Отправь боту `/start` — должно прийти приветствие.
2. Пришли реальное фото кроссовок — придёт разбор кадра с советами.
3. Пришли реальный текст описания — придёт переписанный продающий вариант.
4. Прогони так 5–10 своих настоящих объявлений и оцени, полезны ли советы.

## Из чего состоит проект

- `bot.py` — сам бот: принимает фото и текст, отправляет ответы.
- `gemini_client.py` — связь с нейросетью (две функции: разбор фото, рерайт текста).
- `prompts.py` — тексты-инструкции для нейросети. **Их можно править**, чтобы
  менять стиль советов, не трогая остальной код.
- `requirements.txt` — список нужных библиотек.
- `.env.example` — образец файла с секретами (сам `.env` в git не попадает).
- `api/webhook.py` — точка входа для деплоя на Vercel (вебхук, см. ниже).
- `vercel.json` — настройки деплоя на Vercel.
- `set_webhook.py` — утилита включить/выключить вебхук после деплоя.

---

## Деплой на Vercel (чтобы бот работал всегда, без включённого Mac)

Локальный запуск (`python bot.py`) удобен для проверки, но бот живёт только
пока включён компьютер. Чтобы бот работал круглосуточно бесплатно, его можно
выложить на **Vercel**. Там бот работает в режиме **вебхука**: не он опрашивает
Telegram, а Telegram сам присылает ему каждое сообщение HTTP-запросом.

**Важно про сеть.** Vercel — зарубежный хостинг, поэтому там нет российских
блокировок: и Telegram, и Gemini доступны напрямую. Прокси (`GEMINI_PROXY_URL`)
и VPN, которые нужны для локального запуска в России, на Vercel **не нужны** —
эти переменные там просто не задавай.

Шаги (делается один раз):

1. Залей проект на GitHub (если ещё не залит).

2. Установи Vercel CLI и войди:
   ```
   npm i -g vercel
   vercel login
   ```

3. Из папки проекта запусти деплой:
   ```
   vercel --prod
   ```
   Vercel спросит пару вопросов (подтверждай по умолчанию) и выдаст адрес вида
   `https://твой-проект.vercel.app`. Запомни его.

4. Пропиши секреты бота в настройках Vercel (Project → Settings → Environment
   Variables) — те же, что в `.env`:
   - `TELEGRAM_BOT_TOKEN`
   - `GEMINI_API_KEY`
   - `TELEGRAM_WEBHOOK_SECRET` — придумай любую случайную строку (защита вебхука).

   Прокси (`GEMINI_PROXY_URL`) на Vercel добавлять **не нужно**.

   После добавления переменных сделай ещё раз `vercel --prod`, чтобы они
   применились.

5. Включи вебхук — скажи Telegram, куда слать сообщения. Локально в `.env`
   пропиши тот же `TELEGRAM_WEBHOOK_SECRET`, что задал на Vercel, и запусти:
   ```
   python3 set_webhook.py https://твой-проект.vercel.app
   ```
   Проверить, что вебхук встал: `python3 set_webhook.py --info`.

6. Готово — напиши боту в Telegram. Компьютер можно выключать, бот работает сам.

**Вернуться к локальному запуску.** Сначала выключи вебхук
(`python3 set_webhook.py --delete`), потом снова запускай `python bot.py` —
иначе Telegram будет слать апдейты и на Vercel, и в polling одновременно.

---

## Сколько это стоит

- Telegram и сам бот — бесплатно.
- По умолчанию бот использует **Gemini 3.5 Flash** — быструю и дешёвую модель,
  у Google обычно есть бесплатный лимит запросов для старта.
- Захочешь более мощную модель — в файле `.env` раскомментируй строку
  `GEMINI_MODEL=gemini-3-pro-preview` (качественнее, но дороже и медленнее).

## Что дальше (после проверки первой версии)

- **Цена** — полуручной вариант: продавец сам вводит 2–3 цены похожих объявлений,
  нейросеть даёт вывод «дорого / нормально / дёшево».
- **Спрос** — приблизительная прикидка (не точные данные Авито, а общая оценка).
- **Красивый интерфейс** (мини-приложение в Telegram) — если идея взлетит.
